# CORE (REQUIRED) — the always-on floor. The whole module RUNS, and the full
# self-test PASSES, with only these installed. No model downloads, no network.
#   * numpy        — vectors, the seeded bootstrap, linear algebra
#   * scikit-learn — TF-IDF (content-axis fallback) + cosine similarity
#   * scipy        — OPTIONAL-but-listed: only used by fit_transfer's optional
#                    exponential-decay fit (curve_fit). The module degrades
#                    gracefully (linear-only) if scipy is absent, so it is safe
#                    to drop on a minimal install. Kept in CORE because the
#                    'full' tier curve fit is materially better with it.

scikit-learn>=1.0

# use — they are weights, not pip packages, so no extra requirement line is
